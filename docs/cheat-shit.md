# tetra_demod

Вхід: baseband IQ, **WAV int16, 2 канали (I,Q)** (fs береться із заголовка) або raw `.cs16` + `--fs`.
Тракт: ресемплінг -> 72 кС/с (4 sps) -> RRC -> пошук burst'ів -> timing -> диф. демодуляція -> дібіти.
Вихід: текстовий файл burst'ів (див. нижче). Канального декодування і кореляції зі sync-послідовностями **немає**.

```bash
cd /home/d7/Public/repos/tetra

# базовий запуск
python3 -m tetra_demod rec_72e3.wav -o bursts

# raw int16 interleaved I,Q: fs обов'язковий
python3 -m tetra_demod rec.cs16 --fs 192000 -o bursts

# будь-який fs на вході (ресемплінг до 72 кГц автоматично), напр. 480 кГц
python3 -m tetra_demod baseband_410e6_part000.wav -o bursts

# графіки: обвідна/підлога/пороги + діаграма диф. символів
python3 -m tetra_demod rec_72e3.wav -o bursts --plot
```

# Перед обробкою: пам'ять і діагностика

```bash
cd /home/d7/Public/repos/tetra

# лише оцінка пам'яті (код 0 вистачає, 2 не вистачає)
python3 -m tetra_demod rec.wav --mem-only

# повний аналіз БЕЗ запису burst'ів + звіт у JSON (його зручно вставити у чат)
python3 -m tetra_demod rec.wav --diagnose-only --report health.json

# для автоматизації: degraded теж вважати помилкою (код 1)
python3 -m tetra_demod rec.wav -o bursts --strict; echo "exit=$?"
```

Коди виходу: `0` ok/degraded, `1` degraded за `--strict`, `2` failed (є ERROR).
Статус: `ok` -> `degraded` (WARN, результат є) -> `failed` (ERROR, результат ненадійний або зупинено).

# Тюнінг параметрів

Усі параметри в одному місці: `tetra_demod/config.py`, секція **CONSTANTS**.
З командного рядка: `--set група.параметр=значення` (можна повторювати).

```bash
cd /home/d7/Public/repos/tetra

# показати всі поточні значення
python3 -m tetra_demod --print-config

# пошук burst'ів: порог входу/виходу, мінімальна довжина
python3 -m tetra_demod rec.wav -o bursts --set search.on_db=10 --set search.off_db=6
python3 -m tetra_demod rec.wav -o bursts --set search.min_len_sym=50

# суцільний сигнал без пауз: шумова підлога задається вручну (|y|^2) або по блоках
python3 -m tetra_demod rec.wav -o bursts --set search.noise_mode=fixed --set search.noise_fixed=0.001
python3 -m tetra_demod rec.wav -o bursts --set search.noise_mode=local

# відсіяти не-TETRA burst'и за когерентністю (0 = не відсіювати)
python3 -m tetra_demod rec.wav -o bursts --set quality.min_coherence=0.5

# 8 відліків на символ (144 кГц)
python3 -m tetra_demod rec.wav -o bursts --set front.sps=8

# вимкнути корекцію частотного зсуву (для порівняння)
python3 -m tetra_demod rec.wav -o bursts --set freq.enabled=false

# політики: пам'ять (abort|warn|off) і здоров'я (continue|abort)
python3 -m tetra_demod rec.wav -o bursts --set memory.policy=warn
python3 -m tetra_demod rec.wav -o bursts --set health.policy=abort
```

NOTE: таблиця дібітів (`mapping.dibit_by_quadrant`) міняється лише в `config.py`, не через `--set`.


# Формат виходу (bursts.txt)

Один рядок = один burst. Колонки:

┌───┬────────────────────────────────┬──────────┐
│ # │ Поле                           │ Приклад  │
├───┼────────────────────────────────┼──────────┤
│ 1 │ t_start_s                      │ 0.069667 │
├───┼────────────────────────────────┼──────────┤
│ 2 │ n_sym                          │ 256      │
├───┼────────────────────────────────┼──────────┤
│ 3 │ freq_hz (залишковий зсув)      │ +399.7   │
├───┼────────────────────────────────┼──────────┤
│ 4 │ coherence (1 ідеально, ~0 шум) │ 0.972    │
├───┼────────────────────────────────┼──────────┤
│ 5 │ phase_rms_deg                  │ 3.5      │
├───┼────────────────────────────────┼──────────┤
│ 6 │ flags: - або LOWCOH,NEARLIM    │ -        │
├───┼────────────────────────────────┼──────────┤
│ 7 │ bits (2 біти на символ)        │ 0011...  │
└───┴────────────────────────────────┴──────────┘

```bash
# лише надійні burst'и (когерентність > 0.9)
awk '$4>0.9' bursts.txt > good.txt

# лише без прапорців
awk '$6=="-"' bursts.txt > clean.txt

# скільки burst'ів і медіана зсуву
wc -l < bursts.txt
awk '{print $3}' bursts.txt | sort -n | awk '{a[NR]=$1} END{print "median freq:", a[int((NR+1)/2)]}'
```


# Обмеження (щоб не забути)

- Немає кореляції зі sync/training-послідовностями DMO і кадрування: на виході «сирі» біти burst'ів. Послідовності брати з ETSI EN 300 396-2.
- Відображення дібітів (00:+π/4, 01:+3π/4, 11:-3π/4, 10:-π/4) з пам'яті; ЗВІРИТИ з ETSI EN 300 392-2.
- Тести лише на синтетиці (BER=0 узгоджено з власним генератором, не з ефіром). Усі пороги діагностики підібрані на синтетиці.
- Тонкий зсув частоти однозначний лише в межах ±2250 Гц (symbol_rate/8); грубий зсув діагностується, але не виправляється.
- Файл завантажується в пам'ять повністю (потокової обробки блоками немає).
